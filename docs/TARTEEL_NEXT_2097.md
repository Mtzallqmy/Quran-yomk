## سلامة المحتوى والتوقيع

نجح فحص corpus حفص v2 وفحوص Node العشرون عند خط الأساس. يبلغ corpus
6,236 آية وتُثبّت وثيقة المصدر بصمة مستقلة لإصدار النص. تُشغّل اختبارات
Flutter للمطابقة مع صفحات المصحف وأوضاع العرض إضافة إلى فحوص Node.

`tarteel-publish-preview.yml` الأصلي مرتبط بمرشح 2096 المحدد. ملف إعادة تركيب
توقيع 2096 مرتبط ببصمة APK 2096، ولذلك يتطلب تحديث 2097 التوقيع بالمفتاح
الأصلي أو توقيع APK المرشح نفسه خارجيًا بذاك المفتاح، ثم فحص الشهادة والترقية
دون حذف التطبيق. أي ملف غير موقّع يُعامل كمخرج بناء داخلي.

## ملاحظات المرشح 2097

- الرئيسية تبدأ بالورد وموضع القراءة. تعرض آية للتدبر من حزمة حفص المضمّنة،
  مع رابط إلى الآية في المصحف، وتتكيف مع الشاشات الواسعة والخط الكبير.
- «رحلتي مع القرآن» تسجّل الصفحات التي يؤكد المستخدم إتمامها وتتيح تعديل
  الهدف اليومي وبدء ختمة جديدة. العلامات السابقة تبقى في مفاتيحها الأصلية.
- «مواضعي وملاحظاتي» تحفظ الأسماء والملاحظات على الجهاز بمعرّفات الآيات،
  وتسترجع الصفحة من الخريطة الرسمية. تتوفر إجراءات التحرير من العرضين
  المرئي والنصي.
- «عبادتي» تجمع الصلاة والأذكار والتنبيهات، وتعرض اتجاه القبلة من الشمال
  الحقيقي اعتمادًا على المدينة المحفوظة. تعرض الفجر والمغرب مع التاريخ
  الهجري الحسابي، وتحفظ عداد التسبيح محليًا.
- وثائق الخصوصية والشروط متاحة دون اتصال.
- اسم المرشح `0.9.4-beta.1`. يبني Flutter حزمة ARM64 منفصلة بكود 2097،
  مع بقاء الحد الأدنى API 26.

## الاختبارات والحدود المتبقية

- الاختبارات المحلية تشمل التنقل وتكبير الخط وتطابق النص والأجزاء والصفحات،
  وحفظ المواضع والورد والملاحظات، وحساب القبلة من مدن مختلفة، وحفظ العدّاد.
- نجح 20 اختبارًا لمسار سلامة النص و23 اختبارًا لعقود خدمتي Neon. راجع
  GitHub Actions لنتائج الاختبارات على كل التزام.
- فحص صلاحيات Neon المباشرة أظهر دور عميل النسخ على جدولي النسخ والإعدادات
  مع RLS، ودور قراءة الفهرس على ستة عروض عامة. تعديلات هذا المرشح تحفظ
  بياناتها على الجهاز، ولذلك لم تتطلب ترحيلًا أو إنشاء جداول. يوجد سجل
  ترحيل 2096 القائم في `database/neon/releases/2096.sql`.
- يتطلب المرشح الموقّع المفتاح الأصلي الخاص بمعاينة 2096. مسار العمل *Tarteel
  preview 2097* يبني أولًا، ثم يطابق شهادة التوقيع، ويختبر الترقية الفعلية
  والتثبيت النظيف عند تهيئة توقيع المعاينة. تُضبط أسرار
  `TARTEEL_PREVIEW_KEYSTORE_BASE64` و`TARTEEL_PREVIEW_KEYSTORE_PASSWORD`
  و`TARTEEL_PREVIEW_KEY_ALIAS` و`TARTEEL_PREVIEW_KEY_PASSWORD` في بيئة
  GitHub `tarteel-preview-signing`. يُفعّل التشغيل عند الدفع عبر متغير
  المستودع `TARTEEL_PREVIEW_SIGNING_ENABLED=true`.
- توسعة خدمات الاستماع والإذاعة، مزامنة سجلات القراءة، سير المراجعة العلمية
  في الإدارة، استوديو الآيات، وإضافة حزم جديدة مرخّصة تحتاج أعمالًا تالية.
  نتائج اختبار الترقية التاريخية تخص 2095 ← 2096.
