# ترتيل — تجربة المصحف المعزولة عن الإصدار 2092

## المرجع الدقيق

- آخر إصدار منشور: `v0.9.1-beta.1-preview.2092`.
- قاعدة الفرع: `8d174003e4f1337c0d58f8b0a37bb373f5c981a2`.
- فرع العمل: `experiment/tarteel-mushaf-surah-2092`.
- ليس ترقية رسمية، ولا تفويضًا بالنشر أو الدمج.
- صيغة التطبيق التجريبي: `app.tarteel.tarteel.trial`، مُعدّة للتركيب بجانب `app.tarteel.tarteel`.

## التغييرات المنفذة في أول شريحة

- عميل HTTP للقراءة فقط لـ Surah API مع كشف المشاريع الحقيقي والتحقق من مدخلات المسارات.
- عارض محتوى اختباري عند اختيار آية، يُعرض فقط عندما يُبنى التطبيق بالمتغير `TARTEEL_ISOLATED_TRIAL=true`.
- لا تُنسخ استجابات Surah إلى Neon أو SQLite أو أصول APK؛ وتبقى حقوق المحتوى مرهونة بالتحقق لكل مشروع.
- عزل بصمة التطبيق التجريبي، وتعطيل تهيئة وتسجيل رسائل Firebase Push لتفادي التسجيل الثاني للإشعارات.
- Workflow منفصل يختبر ويُخرج APK إلى GitHub Actions Artifacts **دون إنشاء GitHub Release أو Tag أو تعديل أي قاعدة بيانات**.

## الوضع الحالي لمصادر القرآن — دون حذف خطير

- المصدر المرجعي الحالي تحت `data/quran/canonical/v1` مبني على لقطة موثقة محليًا لـAlQuran Cloud.
- ملفات `IslamicContentRepository` لا تزال تُستخدم في تفسير الآيات والتقسيم وبعض مزايا المكتبة.
- صفحات SVG موجودة في `MushafPageRepository` وحزمها الثقيلة خارج APK.
- فهرس Quranpedia مدمج بواقع 6100 موضوع و3673 آية مغطاة على هيئة وسوم متداخلة.
- **لم تُحذف الأصول القديمة**: يجب أولًا الحصول على مصدر النص العثماني البديل المصرح به، وإعداد مقارنة حرفية وفحص الحقوق ثم تحويل الاستدعاءات واختبارات الترحيل. لا تنفذ عملية إسقاط أو تغيير إنتاجي في قاعدة البيانات لأجل تجربة غير معتمدة.

## قيود مهمة عند التجربة

1. الحزمة التجريبية مُوقّعة بتوقيع Debug، وليست تحديثًا فوق APK رقم 2092، بل تطبيق إضافي منفصل.
2. اختبرها إلى جانب النسخة الأصلية، ولا تحذف النسخة الأصلية من الهاتف.
3. عرض Surah في هذا البناء مرحلة تجريبية: لا توجد بعد مراجعة شاملة لترخيص كل مشروع أو تكامل كامل للتفاسير.
4. التطبيق التجريبي لا يسجل إشعارات Push في الإنتاج، ومزود API الخاص ببعض وظائف ترتيل يُعيَّن إلى نطاق غير فعّال عمدًا في Workflow لحماية الإنتاج، ولهذا قد لا تعمل فيه وظائف الراديو/الخدمات القديمة المعتمدة على ذلك المزود.
5. لا يحق اعتماد الإصدار أو تغيير النسخة المرجعية أو إزالة الملفات النصية القديمة إلا بعد مراجعة نتائج الاختبارات وتفويض صريح من مالك التطبيق.

## معيار استكمال التنفيذ قبل الاعتماد

- مصدر عثماني رسمي مرخص وموثق مع بصمات SHA256.
- فحوص كاملة للـ6236 آية والـ604 صفحات، والاختلافات بين إصدارات الرسم.
- نقل الاعتماديات القديمة وترحيل تنزيلات المستخدم بسلامة.
- تلوين موضوعي حقيقي دون تحريف أو ادعاء شمول غير موجود.
- إغلاق فجوات الترخيص والتوثيق، ثم إزالة الملفات المتكررة التي ثبت خمولها من شجرة الكود.
- APK تجربة ناجح ثم موافقة المالك المنفصلة على أي إصدار معتمد.
