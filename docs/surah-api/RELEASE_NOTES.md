# ترتيل 0.9.1-beta.2 — معاينة 2093

- قائمة تفسير ديناميكية من المشاريع المنشورة في الواجهة الرسمية، مع تفسير الآية والإعراب وكلمات المصدر وفوائد الصفحة عند توفرها.
- القارئ الحالي والنص القرآني والتلاوات والإذاعات والأذان والتنزيلات ومواضع القراءة محفوظة.
- طلبات محدودة المهلة والمحاولات، مع إلغاء النقل عند تجاوز المهلة. فشل المصدر لا يمنع التلاوة أو القراءة.
- بيانات Neon وصفية فقط؛ لا نسخ دائم لنصوص التفاسير أو الصور قبل التحقق من حقوقها. الإسناد في المصادر وحقوق المحتوى.

المصدر يعاني أخطاء500 وتأخرًا متقطعًا وقت التحقق؛ قد لا تتوفر بعض المواضع رغم ظهور المشروع في الفهرس. ليس هذا إصدارًا يدّعي اكتمال استبدال النص الرسمي أو مصحف تجويد محقق جديد.

هوية التوقيع هي هوية معاينة2092/2091 نفسها. لا توافق توقيع2074 الأصلي. اختبار ترقية الهاتف الفعلي منفصل عن فحص الشهادة والبناء.
